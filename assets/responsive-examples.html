.flex-container { display: flex; flex-direction: column; /* Mobile: stack */ gap: 16px; } @media (min-width: 768px) { .flex-container { flex-direction: row; /* Desktop: side-by-side */ } }

4. Responsive Typography

Font sizes scale appropriately for different screen sizes

Heading (scales: 18px → 20px → 24px)

Body text should be readable on all devices. Mobile text: 14px, Desktop: 15px

Line height should be generous for readability. Aim for 1.5-1.6 on body text.

/* Mobile first */ h1 { font-size: 24px; } p { font-size: 14px; } @media (min-width: 768px) { h1 { font-size: 28px; } p { font-size: 15px; } } @media (min-width: 1100px) { h1 { font-size: 36px; } p { font-size: 16px; } }
✅ Always ensure text is readable: minimum 14px on mobile, 16px on desktop

5. Responsive Forms

Full-width inputs on mobile, side-by-side on desktop

@media (min-width: 768px) { .form-row { display: flex; gap: 16px; } .form-row .form-group { flex: 1; } }

6. Responsive Buttons

Full-width on mobile, auto-width on desktop. Min 44px height for touch.

.btn { padding: 12px 16px; /* Min 44px height */ width: 100%; /* Full-width on mobile */ font-size: 14px; font-weight: 600; } @media (min-width: 768px) { .btn { width: auto; /* Auto-width on desktop */ padding: 10px 20px; } }
✅ Touch-friendly: Minimum 44x44px for button targets
